# Installing Holodor

Holodor has one install guide per device. The image, the bootloader files and several steps differ between devices, so follow the guide for the device in your hands:

- **AYN Odin 3:** [INSTALL-odin3.md](INSTALL-odin3.md)
- **Retroid Pocket 5:** [INSTALL-rp5.md](INSTALL-rp5.md)

Downloads for both are at [holodor.bonesaw.com](https://holodor.bonesaw.com).
