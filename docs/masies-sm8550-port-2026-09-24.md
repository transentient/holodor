## 1. What the image is
Verbatim Valve deckard (Steam Frame) rootfs + swapped kernel + ~100-file overlay.
- scripts/extract_rootfs.py reassembles Valve's OTA from the public RAUC/casync store: https://steamdeck-images.steamos.cloud/vr/20260921.6090922/deckard-20260921.6090922-0.5.0.castr (fallback vr/chunks.castr), parses the .caibx itself, sha256 5c53ff2e... "matches RAUC manifest". Live: vr/ lists builds 20260918..20260923 (newest 20260923.6171412), each with .castr/ .chunks_details.json .manifest.json .raucb; manifest = product steamos, release holo, variant vr, branch main, aarch64, version 0.5.0, steamvr 2.17.10. Image is btrfs (make-steamos-sm8550.sh "btrfs restore").
- Valve bits used as-is: steamos-manager (+ /usr/share/steamos-manager/devices/), steamosctl, gamescope-session infra (gamescope-env-list, gamescope-cleanup, user units), steam.service, Plasma 6.2.5/Qt 6.8.0/KF6 6.1.0/glibc 2.39, PipeWire, NM, polkit helpers, /usr/lib/steam/steam.tar.zst, /etc overlay (/var/lib/overlays/etc/upper), /usr/lib/holo/pacmandb; rootfs pacman.conf has [extra] + [deckard-arch-hotfixes] (install-plasma-extras.sh:138-146).
- Replaced/added: kernel 7.0.14-edge-sm8550 + modules + firmware; own gamescope build (MSM rotation shader + sysfs backlight in-tree; stock backed up to /opt/stock-steamos); libvulkan_freedreno.so = host-built Turnip 26.2.3 from /home/steam/MESA-Drivers (Batocera sync + ROCKNIX ir3 UBO patches per MESA-Easy-Manager/docs/PATCH_SOURCES.md) + host libdisplay-info.so.3; MangoHud kept stock; lsfg-vk from host /usr/local/lib; Box64 built in bwrap inside the rootfs (SD8G2) for Decky; InputPlumber 0.78.1 tarball + local libiio; kscreen/plasma-nm 6.2.5, networkmanager-qt 6.14, Gear 26.04.2 built in bwrap; ARM-Manager python apps.
- Steam client: NOT Frame's tarball. install-complete-steam-client.sh rsyncs a complete bootstrapped ARM client from the host's ~/.local/share/Steam (steamdeck_publicbeta; fallback SteamOS-Ubuntu vendor/SteamARM/install-steam-arm pulling client-update.steamstatic.com/steam_client_steamdeck_publicbeta_linuxarm64), strips accounts, writes steam.cfg BootStrapperInhibitAll etc. RUNSTEAM.sh drops -deckard -vrgamepadui, uses -gamepadui -steamos3 -steampal -steamdeck -noverifyfiles -noshaders -inhibitbootstrap -nobootstrapperupdate, copies steamrtarm64/steamclient.so -> linuxarm64/ (0 bytes on Frame). sm8550-patch-steamui regex-patches minified steamui JS. FEX: none shipped; Valve's RUNSTEAM block expects steamapps/common/FEX-Emu/fex-compat-tool (Steam-delivered).
- Bootloader: ROCKNIX ABL 1.1.8. boot/KERNEL = Android bootimg (bootimg.abl.cfg bootsize 192 MiB) = gzip(Image)+14 DTBs + initramfs-tools initrd. Cmdline (kernel/lib/cmdline.sh): clk_ignore_unused pd_ignore_unused quiet loglevel=0 systemd.show_status=0 systemd.log_level=err rw rootwait root=UUID=<sd> masi.ufsroot=PARTLABEL=STORAGE rootfstype=ext4 errors=remount-ro mem_sleep_default=deep ufshcd_core.uic_cmd_timeout=3000; image builder patches the 512-byte cmdline in place.
- Partitions: MBR; p1 FAT32 BOOT 512 MiB (KERNEL); p2 ext4 root ~16 GiB; p3 ext4 home grown on first boot (steamos-sm8550-expand-home). Single slot, no A/B, no RAUC/atomupd (steamos-update stub exit 7; steamos-select-branch stub). Internal UFS: ufs-install/install-masios-to-internal.sh shrinks userdata, ROCKNIX 2 GiB FAT32 set msftdata on + boot on (the basic-data typing that bootloops AYN Android per Holodor 09-17), STORAGE 16 GiB root, HOME rest; initramfs hook masi-dual-root-premount picks SD vs UFS.

## 2. Kernel
Own Armbian-derived build (not ROCKNIX, not Valve). external-and-mods/kernel = "MaSi-OS Kernel Updater": vanilla linux-7.0.14 + Armbian sm8550-7.0 (45 patches, config/armbian-manifests/sm8550-7.0.txt) + 30 MaSi overlays in patches/masi/: 1000-1004 qcom HV haptics + rsinput FF bridge; 1005 Thor panel; 1006-1013 = ROCKNIX PR #2952/#2954 deep-suspend UFS/IPCC/tsens (jaewun); 1014/1015 DP audio; 1020-1023 AYANEO panels; 1024 FT5452; 1025/1026 FastRPC SensorsPD gyro (Batocera/suckbluefrog); 1030 a6xx HFI retry slow GMU BW votes + 1031 forbid A740 GMU runtime PM; 1032 rsinput resume center sticks; 1032-1038 log quieting. Armbian GPU ACD OPP + interconnect QoS skipped by default. golden.config: PREEMPT=y, PSI off, CC_OPTIMIZE_FOR_PERFORMANCE, governor performance, RSINPUT=y, HV_HAPTICS=y, FASTRPC=y, ATH12K=m, no CRYPTO_USER_API (iwd cannot run), no RFCOMM. DTS: AYN from Armbian; RP6 = patches/masi/qcs8550-retroidpocket-rp6.dts (LineageOS kernel-ack adapted); AYANEO from ROCKNIX/Teguh. 14-slot chain in ROCKNIX order (DEVICE-MATRIX.md): slot 0 = Odin 3 SM8750 reference blob, slot 3 = Odin 2 Mini reference DTB (kbuild one black-screens), 7/8 SM8650 blobs; reference blobs vendored from "a community SM8550 image". sm8550 vs sm8650: not handled; userland is Frame's, kernel SM8550-only. Firmware: sparse clone of github.com/armbian/firmware (lib/firmware-download.sh), a740_sqe.fw overridden with ROCKNIX/linux-firmware (Armbian's glitches RPCS3), a740_zap alias, Thor ADSP vendored; bundled in image, not from Android at runtime.

## 7. Assessment + ranked borrows
MaSieS ships Valve's actual current Frame userland (0.5.0, 09-21) by tearing the OTA apart, swaps in an Armbian 7.0.14 kernel + ~100 overlay files. Strength: newest Valve bits (steamos-manager DT matching, gamescope-session, Plasma 6.2.5, hotfixes repo) with zero package maintenance. Weakness: not a build system (host artefacts, hand-seeded Steam, unversioned gamescope, JS-patched Steam UI, VR leftovers masked by hand, no OTA), single-device-tested, deep suspend by fiat, msftdata FAT. Holodor's Holo Core preview + PKGBUILDs is the maintainable path; its gap is a stale mash and no steamos-manager.
