## A. Decky Loader on native aarch64 Python (Cliff's #1)

**Goal.** Run Decky's backend on Holo Core's own `python` (3.13.7) as a system package; no FEX, no binfmt namespace, no PyInstaller; Pocknix Control's py_modules run natively; self-update disabled (pacman owns it).

**Current state.**
- `packages/pocknix-decky/PKGBUILD:12-26` pins `_loaderver=v3.2.8-pre1`, downloads the x86_64 PyInstaller onefile `PluginLoader` into `/usr/share/decky-loader/`. Upstream stable is now **v3.2.9 (2026-09-15)**; every release still ships exactly one asset, `PluginLoader` (x86_64). **PR #914 "add Linux arm64 build workflow" is OPEN, unmerged** (would add `PluginLoader-arm64`; built on `ubuntu-24.04-arm`). No upstream aarch64 binary exists today.
- `pocknix-decky-run:23-30`: `unshare --user --mount` + private binfmt_misc + `exec /usr/bin/FEXInterpreter /home/deck/homebrew/services/PluginLoader`. `pocknix-decky-loader.service:22-33`: waits `pidof steam` (60 s cap), Nice 10, `KEEP_SYSTEMD_SERVICE=1`, `USE_CEF_CLOSE_WORKAROUND=0`, `FEX_APP_CONFIG=/usr/share/fex-emu/AppConfig/PluginLoader.json`.
- `pocknix-decky-sync:21-43` seeds the loader binary + `.loader.version` into `~deck/homebrew/services` (version-compared), writes `settings/loader.json` `branch: 1` (prerelease), re-copies `/usr/share/decky-plugins/PocknixControl` every boot.
- Pocknix Control x86-guest workarounds: `py_modules/pocknix_control/system.py:22-35` (`_clean_env` strips PyInstaller's `LD_LIBRARY_PATH`), `updates.py:20-31` (every pacman call through `systemd-run --wait --pipe` because "pacman" resolved into the FEX rootfs), `sdcard.py:67-70` (mkfs through systemd-run into the init namespace).
- Upstream backend (verified in the clone): `backend/pyproject.toml`: `python = ">=3.10,<3.15"`, deps `aiohttp ^3.10.11, aiohttp-jinja2 ^1.5.1, aiohttp-cors ^0.7.0, watchdog ^4, certifi *, packaging ^24, multidict ^6.0.5, setproctitle ^1.3.3`; build backend `poetry_dynamic_versioning.backend`; console script `decky-loader = decky_loader.main:main`. `poetry.lock` pins aiohttp 3.14.3, aiohttp-jinja2 1.6, aiohttp-cors 0.7.0, watchdog 4.0.2, packaging 24.2, setproctitle 1.3.7. `backend/pyinstaller.spec` is the ONLY arch-specific piece (hiddenimports `logging.handlers, sqlite3, decky_plugin, decky`; datas = `locales/`, `static/`).
- Backend runtime facts: aiohttp server on `127.0.0.1:1337` (`localplatform.py:32-36`, env `SERVER_HOST/PORT`); injects into Steam through CEF devtools at `http://localhost:8080` (`injector.py:12`) — Steam opens that port because `pocknix-steam:41` touches `~/.local/share/Steam/.cef-enable-remote-debugging`; plugin backends are `multiprocessing.Process` forks of the loader (`plugin/plugin.py:5,142`) that `setuid/setgid` per `flags` and append `py_modules` to `sys.path` (`sandboxed_plugin.py:72-91`) — i.e. plugins inherit whatever interpreter runs the loader; `helpers.py:94-105` runs `python3` as the unprivileged user to append system+user site paths; `helpers.py:70-90` derives the version string from `importlib.metadata.version("decky_loader")` ("dev" if 0.0.0 — the dynamic-versioning plugin fills it from the git tag); `main.py:8-9` `sys._MEIPASS` chmod is guarded by `hasattr`; `localplatformlinux.py:266-278` falls back to `/home/deck/homebrew` only if `UNPRIVILEGED_PATH` is unset. Updater (`updater.py:141-244`): downloads the GitHub asset named exactly `PluginLoader` into `getcwd()`, writes `.loader.version`, restarts `plugin_loader` (`do_restart`). Frontend `backend/decky_loader/static/` is **gitignored, built from `frontend/` with pnpm + rollup** (`frontend/package.json` `build: rollup -c`), so a source build needs either a node build or a vendored static tarball.

## B. Boot-time trims beyond 09-23

**Goal.** Shorten power-press → Steam first frame on SD and internal, without touching the plymouth design (do not re-derive it: HANDOFF 09-23 "plymouth / boot splash design").

**Current state (measured 09-23 on SD, HANDOFF:49-66,26-28):** splash 3.5-5.7 s, getty ~7.5 s, session ~8.6 s, plymouth quit ~10.5 s, gamescope DRM ~11.1 s (was 15.7 before Type=simple), then 3-5 s black to Steam's first frame. No `systemd-analyze blame/critical-chain` output is recorded anywhere in HANDOFF; the only data points are the getty fix and pocknix-diag's 31 s sleep. **Observation from the numbers: the session is ready (8.6 s) BEFORE the splash quits (10.5 s) — the critical path from 8.6 s on is the cutscene hold (`pocknix-cutscene-wait`: 6 s from plymouth-start ActiveEnter = 3.5-5.7 + 6 → 9.5-11.7 s), not systemd.** Every trim before 8.6 s therefore buys nothing visible unless the cutscene length is also reduced; trims are worth it for internal-storage boots (faster, so the hold is exposed) and for the black gap after 11 s.

## E. Headphone gain staging (hissy, right-heavy)

**Current state.**
- `devices/sm8750/packages/pocknix-bsp-sm8750/AYN-Odin3.conf:13-19` BootSequence: `RX_RX0/RX_RX1 Digital Volume 84`, `HPHL Volume 20`, `HPHR Volume 20`, `ADC2 Volume 10`; remaps `HP Volume` ← `HPHL`/`HPHR` (stereo) — and base `codecs/wcd939x/init.conf` does the same remap.
- Kernel ranges (`build/kernel/sm8750/linux-7.1.3`): `lpass-rx-macro.c:680,3039` `RX_RXn Digital Volume` = -84..+40 dB, 1 dB/step → **84 = 0 dB** (true dB TLV). `wcd939x.c:2821-2822` `HPHL/HPHR Volume` 0..20 **inverted** (20 = register 0 = maximum PA gain) with TLV `line_gain` = `DECLARE_TLV_DB_SCALE(0, 7, 1)` (0 dB base, 0.07 dB step — a bogus TLV inherited from wcd938x; real HPH PA steps are coarser [UNVERIFIED — Qualcomm docs say ~1.5 dB]). So today both channels sit at MAX analog gain, 0 dB digital.
- `HiFi.conf:67` `PlaybackMixerElem "HP Digital"` — **no such control exists on this card** (the only `HP Digital Volume` in ucm2 is wcd934x's; rx-macro has none; the string is copied from Qualcomm/sm8750/MTP/HiFi.conf) → WirePlumber/PipeWire cannot find a hardware volume → **software volume**, hence the sink at 40 % (~-24 dB cubic) is digital attenuation of a max-gain analog path = the textbook hiss. Right-heavy: mixer values are symmetric (HANDOFF 09-23), so either a per-channel software balance stored by WirePlumber, or the analog/USBSS path itself (the August history: the vendor HSJ poke first gave tone on the RIGHT channel only, HANDOFF:3776).
- Base include `codecs/qcom-lpass/rx-macro/HeadphoneEnableSeq.conf`: `RX_HPH PWR Mode LOHIFI`, `RX HPH Mode CLS_H_ULP` (ultra-low-power class-H = the noisiest mode), COMP1/2 on; wcd939x `HeadphoneEnableSeq`: RDAC/COMP/CLSH on.
- `50-no-sink-suspend.conf` keeps the DSP path open forever (needed for the first-sound bug) → the idle noise floor is always audible (HANDOFF:3535 "codec noise floor vs no-suspend tradeoff").
