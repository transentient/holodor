## Device

AYN Odin 3 (Snapdragon 8 Elite). Boots from SD next to Android; an internal install is optional.

## What changed since 20261002

- Desktop Mode has an on-screen keyboard. Touch a text field and it comes up. The keyboard button on the panel shows or hides it at any time.

## Already on Holodor?

Update from Settings (or `pacman -Syu` in desktop mode). No reflash needed.

## Known issues

- The on-screen keyboard has no word prediction.
- Unreal Engine 5 games launch but are not yet playable.
