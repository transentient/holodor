## Device

AYN Odin 3 (Snapdragon 8 Elite). Boots from SD next to Android; an internal install is optional.

## What changed since 20260925

- Kernel 7.1.3-32: controller MCU report rate restored to 250 Hz (fine analog steps).
- Mesa (Turnip) 26.3.0 devel-7: fixes Unreal Engine 5 titles on the A8xx GPU.
- gamescope 3.16.0 rocknix.4286887-4: guard against the red-tinted screen after wake (night-mode NaN).
- Decky Loader 3.2.9 running natively (no FEX) + Pocknix Control 20 with a STICKS page: "Zero stick centres" fixes off-centre sticks and is re-applied at boot.
- Device support 22/23: back paddles work, InputPlumber 0.81 mapping conflicts resolved, stick LED effects animate, boot-time stick calibration, headphone mixer path.
- Desktop mode: no lock screen after sleep.
- Bootloader kit 1.1.8 (ROCKNIX ABL, Armada's vendored build).

## Known issues

- Headphone jack: the release image leaves the headphone output silent. Fixed in device support 23, published to the update repo on 2026-09-29: update from Settings (or `pacman -Syu` in desktop mode), no reflash needed. Speakers are unaffected.
- Unreal Engine 5 games launch but are not yet playable.
