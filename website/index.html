Holodor

A SteamOS-style Arch Linux for the AYN Odin 3 handheld.

Status: pre-release. Holodor works as a daily driver on the developer's device, but no public image has been released yet. The first downloadable image and install guide will appear on the files page when ready.

What it is

Holodor boots the AYN Odin 3 into a Steam Deck-like experience: Valve's Holo Core (the official Arch Linux aarch64 userland behind SteamOS) on top of a mainline-based kernel for the Odin 3's Snapdragon hardware, with gamescope, the native ARM64 Steam client, and FEX for running x86 Windows games through Proton.

What works

  • Steam Big Picture UI, game downloads, and cloud saves
  • x86-64 Windows games via FEX + Proton (Vulkan on the Adreno GPU through Turnip)
  • Wi-Fi, audio (speakers and headphone jack), controls, rumble, suspend/resume
  • Frame generation (lsfg-vk) with a per-game toggle (needs Lossless Scaling from Steam, installed separately)
  • SD-card boot for trying it out, and an internal install that keeps Android dual-bootable

Credits

Holodor stands on the work of several projects: ROCKNIX (kernel and device support), Valve's Holo Core (userland), ArmadaOS (the first SteamOS-like system on the Odin 3, and many device findings), and FEX-Emu. Licensed GPL-2.0-or-later.
